# Contributing

This is an educational Data Structures Laboratory project. Contributions that improve clarity, correctness, testing, or documentation are welcome.

## Suggested workflow

1. Fork the repository.
2. Create a branch for your change.
3. Make a focused change.
4. Compile the program using the commands in the main README.
5. Test the affected menu options with valid and invalid inputs.
6. Update documentation if behaviour changes.
7. Open a pull request describing the change and how it was tested.

## Code guidelines

- Keep functions focused on one responsibility.
- Use meaningful variable and function names.
- Validate user input before changing account data.
- Release dynamically allocated memory.
- Do not claim a test passed unless it was actually run.
- Do not add fake screenshots, sample metrics, or fabricated test results.

## Reporting an issue

Include:
- The menu option used.
- The input entered (use dummy account details only).
- The expected behaviour.
- The actual behaviour.
- Compiler and operating-system details, if relevant.

Never include real banking information or personal financial data.
